# 股票半年度面板

本目录把上一级 CSMAR 原始压缩包整理为可以匹配基金半年持仓的股票底表。原始包、原有核验程序及作者复现代码均不修改。正式面板范围为 **2010-06-30—2026-06-30，共 33 个半年末**；2009-12-31 仅作为滞后计算的初始快照，保存在中间数据，不混入正式结果。

## 直接使用哪张表

| 文件 | 唯一键 | 用途 |
|---|---|---|
| `结果/stock_halfyear.parquet` / `.csv` | `stock_code × date` | 截至本期末的信息快照，包含当期行情、基本面、评级、股数事件和下一半年股票收益 |
| **`结果/stock_holding_controls.parquet` / `.csv`** | **`stock_code × date`** | **匹配本期基金持仓变化。五个核心变量及新增 11 个指标均已滞后半年，带 `_lag` 后缀；不要再次滞后。** |
| `结果/stock_code_bridge.csv` | `holding_code` | 原行情代码自身映射，以及 CSMAR `FormerCode` 明确记载的 248 对北交所旧代码—920 新代码关系 |
| `核验/分期覆盖率.csv` | `date` | 各半年股票数、各变量可用数及五变量同时完整数 |
| `核验/新增基本面分期覆盖.csv` | `date` | 新增 11 个指标的分期非缺失数量；不能要求短历史指标在全部年份同时完整 |
| `核验/构建核验.json`、`核验/独立验收.json` | — | 输入文件 SHA-256、记录数、剔除原因、输出及独立验收结果 |

`stock_code` 是保留前导零的六位字符串；`date` 是整数 `YYYYMMDD`，与现有基金面板的日期格式一致。`asof` 是同一个半年末的日期类型。建议计算时使用 Parquet；CSV 被 Excel 自动打开时可能把证券代码转成数字，应以文本导入。

例如：`stock_holding_controls` 中 `date=20241231, info_date=20240630` 的一行，用 2024-06-30 当时可得的股票信息，解释基金 2024H2 的持仓变化。`bonus_share_factor_6m` 则属于 **2024H2 本身**，用于核对这段持仓变化中的送股影响。股票本期新上市、上期不存在时，滞后变量保留缺失，不能跨期向前填充。

## 样本和原始文件选择

- 按月行情的 `Markettype` 取 1、4、16、32、64，即沪深 A 股、创业板、科创板和北交所；不按当前上市状态或基金是否持有筛选，不主动剔除 ST、退市、金融行业或负净资产股票。B 股不进入人民币 A 股研究面板，原始包完整保留。
- 北交所 2021-11-15 开市，因此剔除 `Markettype=64` 中 2021 年 11 月以前的精选层月记录；2021H2 缺少完整六个月时收益保持缺失。来源：[北交所本所简介](https://www.bse.cn/company/introduce.html)。
- 每个证券代码在其行情首末月份对应的半年之间建立完整日期格，保留中间缺行情的半年。年中退市但存在当半年行情的股票仍有该半年行；缺少半年末行情就不虚构期末市值。
- 2010—2018 年评级使用 `分析师评级及变动115810968` 的 Excel 替代包；其他三段读取 CSV。2018 年以后的两个 CSV 分片都读入。上市状态同样使用 Excel 替代包，不叠加有损 CSV。
- Excel 的工作表范围标记错误，程序直接按 XML 的实际单元格读取，不受 A 列范围标记影响。所有原始缓存附 SHA-256 和字段清单，源包或读取字段改变后重新生成。
- 公司年度信息中的当前/年度行业、名称、经营性质没有无条件回填到历史。本文核心五变量不需要这些字段；它们仍保存在原始包中。

## 统一符号、原始字段和时间规则

以下说明对应当前 `build_stock_panel.py` 的实际计算。`i` 表示股票，`h` 表示半年末（6 月 30 日或 12 月 31 日），`q` 表示截至 `h` 已公告的最新财报报告期。**`q` 不一定等于 `h`**：例如 2024-06-30 时若最新公开的是 2024 年一季报，则 `q=2024-03-31`，不能使用尚未公布的 2024 年半年报。

`q−1年` 指上年相同季度，`Y−1年末` 指上年 12 月 31 日；都按精确股票代码和报告期匹配，不拿邻近报表代替。资产、权益是报告期末存量，利润和收入是年初至报告期末的累计流量。下表中财务金额按原报表的元口径读取，月行情市值从千元乘 1000 转为元，避免估值比率差 1000 倍。

| 来源文件 | 原始字段 | 含义及对应计算 |
|---|---|---|
| 月个股回报率文件 `114059067` | `Msmvttl`、`Msmvosd` | 总市值、流通市值，乘 1000 后为 `market_cap`、`float_market_cap` |
| 同上 | `Mclsprc`、`Mretwd` | 月收盘价；考虑现金红利再投资的月收益率，后者已是小数，不再除以 100 |
| 资产负债表 `114132694` | `A001000000` | 总资产 `A`，用于 ROA、负债率、资产增长 |
| 同上 | `A003100000` | 归母权益 `BE`，用于 BM、PB、ROE |
| 同上 | `A003000000` | 包含少数股东权益的总权益 `TE`，用于推算总负债 `A−TE` |
| 利润表 `114149331` | `B002000000` | 合并净利润 `NI`，用于 ROA，可能包含少数股东损益 |
| 同上 | `B002000101` | 归母净利润 `PNI`，用于 E/P、PE、ROE 和亏损标记 |
| 同上 | `B001100000` | 营业总收入 `REV`，用于收入增长和研发强度；不是单独的营业收入 `B001101000` |
| 同上 | `B001300000`、`B001000000` | 营业利润 `OP`、利润总额 `TP`，两者差额用于营业外损益占比 |
| 同上 | `B001216000` | 研发费用 `RD`，用于研发费用强度 |
| 年、中、季报基本情况 `114653443` | `Accper`、`Annodt`、`Reptyp` | 报告期、原始公告日和季度类型，用于选择当时已经公开的报告 |
| 资产负债表、利润表 | `Typrep`、`IfCorrect`、`DeclareDate` | 合并口径及更正信息；此处 `DeclareDate` 为更正日期，不是初次公告日 |

**TTM 的共同计算规则**：对 `NI、PNI、REV、OP、TP、RD` 分别应用下式，不能把不同利润口径混用。

```text
若 q 为年报： X_TTM(q) = X(Y年全年)
若 q 为季报/半年报： X_TTM(q) = X(Y年年初至q) + X(Y−1年全年) − X(Y−1年年初至同季)
```

例如，当时可得的最新报告是 2024Q1，归母净利润分别为 2024Q1 的 30、2023 全年的 100、2023Q1 的 20，则 TTM 归母净利润为 `30+100−20=110`，覆盖 2023 年 4 月至 2024 年 3 月。不能用 `30×4=120`，也不能用截至 2024 年 6 月的未公告利润。后文算例均为说明用的假设数字，同一公式中的金额单位保持一致。

每个必需报表组件都需要原始公告日。无更正时从原公告日起可用；有更正时从原公告日和最后更正日两者较晚者起可用。组件缺失、日期缺失或晚于 `h`，相应指标为空；不拿未来数值回填，不把缺失当作零。年报 TTM 只需要当前年报利润，不额外要求上年利润，但 ROA/ROE 仍需要上年同期资产/权益。最新报告期的选择不因指标缺失而退回旧期。

## 五个核心变量

| 字段 | 定义 | 单位和注意事项 |
|---|---|---|
| `size` | `ln(1 + market_cap / 1,000,000)` | 人民币百万元口径；不是基金规模。原文美元单位的中国市场对应口径 |
| `bm` | 最新已公告合并报表的归母权益 / 本期末股票总市值 | `A003100000 / (Msmvttl × 1000)`；保留负权益，不以总权益替代缺失归母权益 |
| `roa` | TTM 合并净利润 / 同比平均总资产 | `B002000000_TTM / ((A001000000_t + A001000000_{t-1年}) / 2)`；中国原始报表构造口径，不声称等同 WRDS 已加工 ROA |
| `ret6m` | 半年内六个月 `Mretwd` 的 `∏(1+r)-1` | 含现金红利再投资，十进制；是半年累计收益，区别于基金旧面板的几何平均月收益 |
| `rec_change` | 本期末券商评级共识 − 上一期末共识 | 买入=5、增持=4、中性=3、减持=2、卖出=1，**正数表示更乐观** |

主表保留上述当期快照；持仓匹配表提供 `size_lag, bm_lag, roa_lag, ret6m_lag, rec_change_lag`。`controls_complete` / `controls_complete_lag` 仅表示这五列同时非缺失，不代表代码变更、股数事件和全部财报版本均已获得最终核实。无评级不等于评级不变，不填零。

`Msmvttl`、`Msmvosd` 从千元乘 1000 统一到元；`Mclsprc` 为元/股。半年末只使用 6 月或 12 月的源记录，不用之前月份的市值顶替。`price_date` 保留该月实际最后成交日，长期停牌和缺日期可以据此识别。原始月表及清洗后的月度行情保存在中间数据，便于后续另算股票因子 alpha；本次没有把基金净值 alpha 冒充股票 alpha。

`ret6m_fwd` 是精确下一半年键的股票累计收益，只用于结果变量/组合业绩；不进入持仓控制表。2026-06-30 行的未来半年收益全部为空，本次不使用下载包里 2026 年下半年的未满半年行情。

### 1. 股票规模 `size`

- **输入**：半年末所在月的 `Msmvttl`，先乘 1000 得到人民币元市值 `MC_h`。没有当年 6 月/12 月记录时，不用 5 月/11 月替代。
- **公式**：`size(i,h) = ln(1 + MC_h / 1,000,000)`，取自然对数。先把元转为百万元，再加 1，最后取对数。
- **边界**：市值必须为正；零、负值或缺失得到缺失。代码虽使用 `log1p`，也没有把零市值当成有效规模。
- **例子**：市值 100 亿元时为 `ln(10001)≈9.21044`。这个字段没有单位，不是市值本身，也不是基金规模；其常数取决于明确的币种和百万元单位。

### 2. 账面市值比 `bm`

- **输入**：最新已公开报告期 `q` 的归母权益 `BE_q=A003100000`，以及半年末总市值 `MC_h`。分子输出为 `book_equity`。
- **公式**：`bm(i,h)=BE_q/MC_h`。账面权益无需 TTM，也不取前后两期平均。
- **边界**：资产负债表在 `h` 可用，归母权益非缺失，且市值为正。权益为负时保留负 BM，为零时 BM=0；不能以包含少数股东权益的 `A003000000` 替代缺失归母权益。
- **例子**：归母权益 20 亿元、市值 100 亿元，BM=0.20；权益为 −2 亿元时 BM=−0.02。分子是最近可得财报存量，分母是本期末市场估值，两者日期不必相同。

### 3. 总资产收益率 `roa`

- **输入**：合并净利润 `NI_TTM(q)`、当期总资产 `A_q`、上年同季总资产 `A_(q−1年)`。
- **公式**：`roa_average_assets=(A_q+A_(q−1年))/2`；`roa=NI_TTM(q)/roa_average_assets`。
- **边界**：利润 TTM 必需组件和两期资产报表都在 `h` 可用，两期资产均为正。保留负利润及负 ROA，不要求盈利。平均资产是同比两端均值，不是上季度均值，也不是 12 个月资产均值。
- **输出细节**：`income_ttm` 保存这一口径的合并净利润，但当前程序对它施加与 ROA 相同的资产可得性筛选；即使利润本身可得，缺少合格资产时 `income_ttm` 也为空。E/P 的 `parent_income_ttm` 另行计算，不受这项筛选影响。
- **例子**：TTM 合并净利润 12 亿元、两期资产 100 和 140 亿元，平均资产=120 亿元，ROA=0.10，即 10%。

### 4. 过去半年累计收益 `ret6m` 与下一半年收益 `ret6m_fwd`

- **窗口**：6 月末对应当年 1—6 月，12 月末对应当年 7—12 月。取各月 `Mretwd`，不从两个收盘价反推含息收益。
- **公式**：`ret6m(i,h)=(1+r_1)×…×(1+r_6)−1`。输入和输出均为小数，0.08 表示 8%。现金红利再投资已包含在源收益中，不再重复加股息。
- **完整性**：股票—月份必须唯一；`observed_months` 是原始月记录数，`return_months` 是非缺失 `Mretwd` 数。只有 6 个有效月才计算；IPO、退市或缺月导致不足 6 个时为空，不补零、不年化。整个半年没有记录时这两个计数也可能为空。
- **例子**：六个月每月均为 1%，半年收益为 `1.01^6−1≈0.06152`，不是 0.06，也不是几何平均月收益 0.01。
- **未来收益**：`ret6m_fwd(i,h)=ret6m(i,h+1个半年)`，通过精确股票—下一半年键连接；下一半年不存在或其收益不完整则为空。这是结果变量，不能放入当时的信息集。

### 5. 分析师评级变动 `rec_change`

- **输入**：评级包中的 `Stkcd, ReportID, InstitutionID, Brokern, Rptdt, DeclareDate, Stdrank`。此表 `DeclareDate` 是评级发布日期，与财报表同名字段的含义不同。
- **标准化**：买入=5、增持=4、中性=3、减持=2、卖出=1；不能识别的评级排除。报告可用日为 `max(撰写日, 发布日)`，要求发布日期有效；最终时间窗口也要求撰写日有效。
- **先形成共识**：同报告去掉预测年度重复；以 `h−180天` 至 `h` 的闭区间筛选报告可用日，并要求撰写日不早于 `h−180天`。每家券商只留最近可用报告；同日先取最新撰写日，仍并列取评级中位数。再对各券商最新评级等权取中位数，得到 `rec_consensus(i,h)`。
- **公式**：`rec_change(i,h)=rec_consensus(i,h)−rec_consensus(i,h−1个半年)`。严格对应上一个半年，不跳过没有覆盖的期次。
- **例子**：当前三家券商评级为 5、4、4，共识=4；上期共识=3.5，则变动=+0.5。评级共识和变动可以是半整数。
- **缺失与解释**：任一期无有效共识，变动为空；两期共识相同才为 0。正值表示整体更乐观，但券商覆盖变化也会改变中位数，不等于同一券商上调次数。无覆盖时 `rec_brokers=0`，共识与变动仍不填零。具体去重流程见后文评级章节。

## 新增 PE 与中国市场补充指标

下表为当期快照字段；持仓匹配表提供同名加 `_lag` 的版本。比例都是小数，PE、PB 是倍数。财报类指标使用截至快照日已公告、且通过更正日期检查的财报；流通市值占比直接使用期末行情。原五变量的 `controls_complete` 定义不变。**当前输出同时保留 E/P 和 PE，未删除任何一列。**

| 字段 | 计算口径 | 有效观测数 |
|---|---|---:|
| `pe_ttm` | 期末总市值 / TTM 归母净利润；归母利润必须 > 0 | 83,108 |
| `ep_ttm` | TTM 归母净利润 / 期末总市值；保留负值与零值 | 101,117 |
| `pb` | 期末总市值 / 最新已公开的归母权益；权益必须 > 0 | 114,900 |
| `roe_ttm` | TTM 归母净利润 / 当期及上年同季归母权益的均值；两期权益均须 > 0 | 101,492 |
| `leverage` | 1 − 合并总权益 / 合并总资产，即资产负债率；资产须 > 0 | 117,886 |
| `asset_growth_yoy` | 最新已公开的总资产 / 上年同季总资产 − 1；上年资产须 > 0 | 109,699 |
| `revenue_yoy` | 本年累计营业总收入 / 上年同期累计营业总收入 − 1；上年收入须 > 0 | 109,349 |
| `nonoperating_profit_share_ttm` | (TTM 利润总额 − TTM 营业利润) / abs(TTM 利润总额)；分母非零 | 103,070 |
| `rd_expense_to_revenue_ttm` | TTM 研发费用 / TTM 营业总收入；研发费用非负，收入为正 | 51,829 |
| `tradable_cap_ratio` | 同一期末流通市值 / 总市值，即 `Msmvosd / Msmvttl` | 118,811 |
| `loss_ttm` | TTM 归母净利润 < 0 为 1，否则为 0；利润缺失时仍缺失 | 103,070 |

**PE 的利润分母为归母净利润 `B002000101`，不是原 ROA 的合并净利润 `B002000000`。** 非年报 TTM = 本期累计 + 上年全年 − 上年同期，年报直接取全年数；不用季度利润简单乘四。PE 只需要利润报表可用，资产报表缺失不会连带阻断 PE。亏损或零利润的 PE 为空，通过 E/P 和 `loss_ttm` 保留信息。市值沿用本项目 CSMAR 月表总市值口径；涉及 A/H 或其他股类时，不声称已另外拼接各股类实际市值。

`parent_income_ttm, revenue_ttm, operating_profit_ttm, total_profit_ttm, rd_expense_ttm, roe_average_equity` 同时保留，便于复算。新增可用日期为 `earnings_ttm_available, balance_yoy_available, revenue_yoy_available, roe_source_available`，相关指标非缺失时均不晚于快照日期。PB、负债率沿用 `book_source_available`。这些日期在数值被阻断的行里可能晚于快照，只解释缺失原因。

### 6. 盈利市值比 `ep_ttm`（E/P）

- **公式**：`ep_ttm(i,h)=parent_income_ttm(i,h)/market_cap(i,h)=PNI_TTM(q)/MC_h`。先独立计算 TTM 归母净利润，再除以正的期末市值；不通过 `1/pe_ttm` 生成，因此能保留亏损股票。
- **可用条件**：归母利润 TTM 的必需报表及其数值完整、全部在 `h` 可用，市值为正。无需资产或权益数据。利润缺失或市值无效时为空。
- **正负值**：市值 100 亿元、归母利润 5 亿元时 EP=0.05（5%）；亏损 2 亿元时 EP=−0.02；利润恰为零时 EP=0。负数和零均是有效观测，不能当成缺失编码。
- **含义**：反映过去 12 个月归母盈利相对本期市场价格的水平，是历史盈利估值特征；不是预测收益率或保证获得的投资回报。

### 7. 市盈率 `pe_ttm`（PE）

- **公式**：`pe_ttm(i,h)=MC_h/PNI_TTM(q)`；必须同时满足市值为正、TTM 归母净利润为正。
- **缺失规则**：归母利润小于或等于零时留空，不输出负 PE 或无穷大；盈利非常小时仍保留很高的 PE，另列极端值核验清单。必需报表和可用日期约束与 E/P 一致。
- **例子**：市值 100 亿元、归母利润 5 亿元，PE=20 倍、EP=0.05，两者互为倒数；亏损时 PE 为空而 EP 仍可为负。它不是以预测盈利计算的动态 PE，也不是单独取上一年度利润的静态 PE。

### 8. 市净率 `pb`

- **公式**：`pb(i,h)=MC_h/BE_q`。分子和分母分别与 `bm` 相同，但互换位置。
- **边界**：市值和归母权益均须为正，且该权益报表在 `h` 可用。负或零权益时 PB 为空，而 BM 仍可为负或零；不使用总权益替换归母权益。
- **例子**：市值 100 亿元、归母权益 20 亿元，PB=5 倍、BM=0.20。只有这些有效正值样本才有 `PB=1/BM`。

### 9. 净资产收益率 `roe_ttm`

- **公式**：`roe_average_equity=(BE_q+BE_(q−1年))/2`；`roe_ttm=PNI_TTM(q)/roe_average_equity`。
- **边界**：利润 TTM 组件、当期和上年同季归母权益均在 `h` 可用；两期权益必须分别为正，不能仅检查均值为正。利润可以为负；负 ROE 保留。
- **例子**：归母利润 6 亿元、两期归母权益 40 和 60 亿元，ROE=`6/50=0.12`，即 12%。使用同比两端平均，未按增发、回购、分红的具体发生天数加权，因此不保证等于年报披露的加权平均 ROE。

### 10. 资产负债率 `leverage`

- **公式**：`leverage(i,h)=(A_q−TE_q)/A_q=1−TE_q/A_q`。`TE` 使用含少数股东权益的 `A003000000`，不是归母权益。
- **边界**：最新资产负债表在 `h` 可用，总资产为正、总权益非缺失。不做 TTM，也不取两期均值。没有用“总资产减归母权益”，否则会把少数股东权益误算为负债。
- **例子**：资产 100 亿元、总权益 35 亿元，负债率=0.65。总权益为负时比率可能超过 1，原值保留并进入核验清单；小于 0 的异常值也不静默裁成零。

### 11. 总资产同比增长 `asset_growth_yoy`

- **公式**：`asset_growth_yoy(i,h)=A_q/A_(q−1年)−1`，直接比较两个同季期末存量。
- **边界**：两期报表和资产值可用，上年资产须为正；当前代码没有额外要求本期资产为正，若源值为零或负仍保留计算结果供核查。任一资产缺失或上年资产不大于零时为空。
- **例子**：本期资产 120 亿元、上年同季 100 亿元，增长=0.20；当 `q=2024Q1` 时比较 2024-03-31 与 2023-03-31，不与 2023-12-31 比，也不是半年环比。

### 12. 营业总收入同比增长 `revenue_yoy`

- **公式**：`revenue_yoy(i,h)=REV(Y年年初至q)/REV(Y−1年年初至同季)−1`。
- **边界**：当前、上年同期利润表在 `h` 可用，两个累计收入值非缺失，上年收入须为正；无需上年全年收入。当前收入为零或负时不自动剔除，所以可能出现 −100% 或更低的值。
- **例子**：最新报告为三季报时，本年 1—9 月收入 90 亿元、上年 1—9 月 75 亿元，增长=0.20。**不是单独第三季度同比，也不是 `revenue_ttm` 的同比变化。**

### 13. 营业外损益占比 `nonoperating_profit_share_ttm`

- **输入和公式**：分别把利润总额和营业利润转为 TTM；`(total_profit_ttm−operating_profit_ttm)/abs(total_profit_ttm)`。差额是税前口径，不能与税后的归母净利润直接相减。
- **边界**：两个 TTM 数值与各自必需报告均可用；利润总额恰为零时为空，负利润总额仍可算。分母取绝对值，因此符号由营业外净损益的方向决定。
- **例子**：TTM 利润总额 10 亿元、营业利润 8 亿元，占比=0.20；若利润总额 −10 亿元、营业利润 −12 亿元，差额仍为 +2 亿元，占比仍为 +0.20，表示营业外净收益抵减了部分营业亏损。
- **解释限制**：比率可能超过 1；不能把它理解为限制在 0—100% 的收入份额。它不覆盖全部非经常性项目，不能据此构造“扣非归母净利润”。

### 14. 研发费用强度 `rd_expense_to_revenue_ttm`

- **公式**：`rd_expense_ttm/revenue_ttm`，研发费用与营业总收入分别按统一 TTM 公式计算。
- **边界**：TTM 研发费用须非负、TTM 收入须为正，所有必需组件都可用。研发费用明确记录为 0 时强度=0；任一研发组成项缺失时强度缺失，不能用零补齐再做差。
- **历史限制**：要求最新报告期不早于 2018-12-31，但这一条件本身不保证可算；例如 2019Q1 仍需要 2018Q1 的研发费用。选中的最新报告不完整时不回退到年报，因此本次首次有效半年快照是 2019-12-31。
- **例子**：TTM 研发费用 0.8 亿元、收入 20 亿元，强度=0.04。字段仅为利润表中的费用化研发，不自动加资本化开发支出。

### 15. 流通市值占比 `tradable_cap_ratio`

- **公式**：`float_market_cap/market_cap=(Msmvosd×1000)/(Msmvttl×1000)`，分子分母取同一股票、同一期末月份。
- **边界**：总市值必须为正，流通市值非缺失；不依赖财报。程序不把结果强制截在 [0,1]，超范围时进入核验清单。
- **例子**：流通市值 60 亿元、总市值 100 亿元，比率=0.60。此处没有用股本变动表的 `float_a_shares/total_shares` 代替，也未剔除战略持股来构造自由流通比例。

### 16. 亏损标记 `loss_ttm`

- **公式**：有效 `parent_income_ttm<0` 时为 1；有效利润大于或等于零时为 0；利润缺失时仍缺失。输出为可容纳缺失值的数值列。
- **边界**：只需要可用的 TTM 归母利润，不需要市值。因此某些没有期末市值的股票可以有亏损标记，却没有 E/P。零利润时标记=0，但 PE 仍为空。
- **例子**：利润 −2、0、5、缺失分别对应 1、0、0、缺失；缺失不是“未亏损”的证据。

### 中国市场适用理由与边界

- **E/P**：在亏损样本中仍有含义，避免 PE 在接近零利润时爆炸。Liu、Stambaugh、Yuan 的中国股票研究强调盈利市值比的价值信息，见 [Size and value in China (2019)](https://doi.org/10.1016/j.jfineco.2019.03.008)。这里是基于可得财报的 TTM 股票特征，不是复刻该文的因子组合、年报时点或小市值筛选。
- **营业外损益占比**：辅助识别营业利润以外的损益对税前利润的影响，但不代表全部非经常性损益，更不是扣非净利润。2017 年前后其他收益、资产处置等分类变化会影响跨期可比性；不能用此指标代替政府补助总额或扣非盈利。[证监会非经常性损益披露规则](https://www.csrc.gov.cn/csrc/c101954/c7451398/content.shtml)采用独立的认定口径。
- **研发费用强度**：用来补充研发费用化投入差异。源字段 `B001216000` 从 2018 年起单列，程序不使用早于 2018 年年报的 TTM，也不将缺项补零；由于最新报告期及所需历史组成项的覆盖约束，本次正式半年面板最早有效值是 **2019-12-31**。研发费用不含全部资本化研发，也不等于统计口径的研发经费，见[国家统计局解释](https://www.stats.gov.cn/hd/lyzx/zxgk/202405/t20240524_1953794.html)。
- **流通市值占比**：补充股份流通结构差异，属于股权结构辅助指标，不是会计盈利指标；不等同于指数自由流通比例、国有持股比例或当期解禁比例。
- **ROE、负债率、增长率**：补充盈利能力、资本结构与扩张。ROE 是同比两端均值口径，不是公告中的加权平均 ROE；收入增长为累计同比，不是 TTM 同比。金融企业与实业企业的资产负债结构不同，应结合行业分别解释。

**模型使用建议**：新增项用于扩展模型或稳健性检验，保留原五变量基准。E/P 与 PE 在正利润样本中互为倒数，PB 与正值 BM 也互为倒数，避免无目的地同时加入。研发指标只在有覆盖的子样本检验，不应让它删掉整个早期样本。扣非净利润、历史国企/实控人性质、股权质押、真实研发总投入等尚缺足够的历史字段或可用日期，本次未以近似字段冒充。

新增指标没有缩尾或删行。`核验/新增估值与基本面极端值.csv` 汇集 PE > 1000、PB > 100、abs(ROE) > 1、abs(E/P) > 1、abs(营业外占比) > 1、研发强度 > 1、流通比例或负债率在 [0,1] 外、abs(资产/收入增长率) > 10 的行。阈值仅供核查，不是错误判定；负净资产也可能使真实负债率大于 1。

## 财报：报告期、公告日、更正日分开

1. 只取合并报表 `Typrep=A`，会计期末只允许 3/31、6/30、9/30、12/31。1 月 1 日等期初/调整行不作为当期财报重复并入。
2. 原始公告日期来自 `IAR_Rept.Annodt`；财务表 `DeclareDate` 是差错更正日期。公告日期缺失或无效的记录不猜测一个披露日。
3. 对每个股票—半年末，先按公告日选出已经公开的最新报告期。选择与财务值是否完整无关：不能因为最新一期缺数据就静默回退到旧财报。
4. 没有更正的数值，从原始报告公告日开始可用。标记已更正的数值，从 `max(原始公告日, 最后一次更正公告日)` 开始可用；已更正但更正日期无法解析时保持不可用。更正之前的原始数值不在包内，因此缺失不能凭空恢复。
5. 非年报的 TTM 利润 = 当期累计利润 + 上年全年利润 − 上年同季累计利润；年报直接用全年利润。分子每个组成报告、当期资产及上年同季资产都必须在快照日期之前可用。任一历史组成部分被晚到更正阻断，就不计算该期 ROA。
6. `book_source_available` 和 `roa_source_available` 保留数值对应的最晚必要日期。被阻断行中这些日期可能晚于快照，用于解释缺失，不能当成当时已知的预测变量。

**这是更正延后使用的保守版本，不是已找回全部原始历史版本的严格财报 vintage 数据。** 数据商没有标记的追溯重述、口径变化和跨证券代码历史版本仍可能影响结果。主表保留 `fin_report_period, fin_announcement, fin_age_days, bs_correction_blocked, roa_correction_blocked` 供检查。

`book_equity, assets, income_ttm, roa_average_assets` 提供可直接复核的分子分母。没有缩尾、删负净资产或删金融行业。`financial_extreme_review` 仅标记 `abs(roa)>1` 或 `abs(bm)>10`，便于检查重组、资产骤变或原始数据问题；不是判定原始数据错误。原行全部保留，详情在 `核验/财务极端值待核验.csv`。

## 评级共识：避免一份报告重复投票

1. 原始四段共 2,284,258 行。同一研究报告因不同预测会计年度而重复；只读取报告身份、日期、券商和标准化评级，不使用预测准确度、乐观偏差等含实际未来 EPS 的字段。
2. 实际可用日为 `max(Rptdt, DeclareDate)`，并要求平台发布日期非缺失；不以撰写日期填补缺失发布日期。`Stdrank` 非五种标准评级时退出本指标。
3. 同股票、同报告 ID 去重；必要字段有冲突时整份报告退出，另存冲突清单。
4. 券商按 `InstitutionID` 识别；缺 ID 时先用全表中唯一的同名 ID 补齐，仍不能确定的才用券商名称标识。该操作只规范主体身份，不填补任何历史评级。

6. 跨券商等权取中位数得到 `rec_consensus`，记录 `rec_brokers` 与 `rec_latest_publication`。`rec_change` 只与精确上一个半年末比较，任一期无共识就缺失。额外生成 2009-06-30 的评级快照供初始差分使用。

这是一套自行构造的中国评级共识，并非直接下载的 IBES `MEDREC`。券商覆盖的增减也会改变共识，后续研究可据 `rec_brokers` 设置覆盖门槛或在固定券商样本上复核。原下载说明中的全库记录数差 375 条仍未解决，不能声称已覆盖数据库全部评级。

## 股数调整与状态：可以算什么，不能混用什么

- `bonus_share_factor_6m` = 本半年除权日落入区间的 SD 事件 `∏(1 + Amount)`。它只是**送红股/送转记录对应的机械股数倍率**，不是所有公司事件的完整复权因子。没有 SD 事件时为 1。
- 在无其他复杂事件且两端持仓数量口径一致时，送股调整后的交易变化可写为 `Q_h / (Q_{h-1} × bonus_share_factor_6m) - 1`。新建仓仍需单独处理；该式尚未针对你的实际基金持仓逐笔验证。
- 现金分红不改变持股数量，不能用其价格复权效果调整股数。`price_factor_bwd` 及 `factor_date` 仅保留作价格核对；未出现历史价格因子时保留缺失，不默认等于 1。
- 配股 RO、拆细 DS、股改 GQ、公开增发 SN 不自动并进送股倍率，保留 `special_share_event_count` 和原始事件清单。特别是 DS 的比率含义不能仅凭字段名猜成 `1+Amount`。
- 除权和新增股份上市跨半年、上市日缺失、股数事件公告日缺失或晚于除权日，会触发 `share_adjustment_review`。跨半年的送股同时标记除权期和股份上市期。还应检查 `code_change_review`。
- `total_shares, float_a_shares, capital_date, capital_change_type` 来自截止期末最近一次股本变动；**总股本增长率不等于每位基金持有股数的自动增长率**。该表没有逐笔公告日期，属于历史实施口径的辅助核对数据，未纳入预测控制变量。
- `last_status_event` 是截至期末既已实施、也已公告的最后一条上市状态事件。没有历史事件就是缺失，不用当前公司快照的正常/退市状态回填历史。对应的实施、公告和可用日期分别保留。
- 分配表不保证囊括所有特殊证券重组事件；没有风险标记也不是全部股份数量处理已经完备的证明。

## 代码匹配边界

沪深旧码与新码可能在某个月同时出现，财报和公告表的历史改码口径也不完全一致。除下面的北交所标识桥外，不自动把 `FormerCode` 关联的历史全部拼成一条股票收益链，更不把公司快照的 `Listdt` 当成每次改码的可靠日期。所有曾用码线索见 `核验/曾用代码待核验.csv`。

北交所 248 对关系采用 CSMAR 公司文件逐对提供的曾用代码，且要求旧码未作为独立代码出现在本次 A 股月行情中、关系一对一。桥表只将持仓旧标识规范到数据商历史记录已经使用的 920 标识，不声称这些股票在历史上就使用 920 代码，也不处理换号生效日。制度背景：[北交所新旧代码对照表](https://www.bseinfo.net/service/code_mapping.html)。本次未逐一下载交易所对照表原件；主体关系证据是本地 CSMAR 文件。

`code_change_review` 提醒该代码涉及曾用码关系，不能直接解释为数据错误，也不要据此机械剔除全部北交所样本。`cross_listed_snapshot` 来自当前 AB/H 交叉码，只作数据核验提示，不能当历史是否跨境上市的控制变量；不同股类市值口径须另行确认。

## 和基金持仓匹配的例子

### 半年滞后怎样构造

匹配表里所有 `_lag` 列都遵循 `X_lag(i,h)=X(i,h−1个半年)`，程序将快照的日期整体向后移动 6 个日历月末，再用股票代码和本期日期精确连接。这里的“滞后”是半年，不是一个交易日或一个财报期，也不是跳过缺失后的上一条有效记录。

| 本期持仓变化区间 | 匹配键 `date` | 要取的信息快照 `info_date` | 例子 |
|---|---:|---:|---|
| 2024 年 1—6 月 | 20240630 | 20231231 | `ep_ttm_lag` 来自 2023 年末的市值及当时可得的财报 |
| 2024 年 7—12 月 | 20241231 | 20240630 | `ep_ttm_lag` 来自 2024 年 6 月末的市值及当时可得的财报 |

`rec_change_lag` 因而是“上半年末共识减上上半年末共识”，`ret6m_lag` 是紧接本期之前的完整半年收益。财报期、公告日和来源可用日的 `_lag` 列也来自同一旧快照，不会在滞后后改用新披露的财报。

上期有股票行但某指标缺失时，保留 `info_date`，对应指标仍为空；上期根本没有该股票行时，`info_date` 及全部滞后列为空。2009-12-31 初始快照仅用于形成 2010H1 的滞后信息。

持仓匹配表中的 `bonus_share_factor_6m, bonus_event_count, special_share_event_count, share_adjustment_review` 保留**本期**事件，用于解释本期持股数量变化，没有滞后。`code_change_review` 是代码关系核验提示，不是历史预测变量。不要把整张匹配表再统一 `shift` 一次。

### 合并代码

以下假设持仓列为 CSMAR 的 `Symbol` 和 `EndDate`，且 `EndDate` 为报告期末，而不是公告日。真实文件列名不同时明确改名。合并不负责 A/C 份额去重，也不会把同一个基金的重复持仓自动相加。

```python
from pathlib import Path
import pandas as pd

root = Path("股票半年度面板/结果")
stock = pd.read_parquet(root / "stock_holding_controls.parquet")
bridge = pd.read_csv(root / "stock_code_bridge.csv", dtype=str)

# holdings = 已读取的基金完整半年持仓；保留基金 ID 和所有原始列。
holdings["holding_code"] = (holdings["Symbol"].astype("string").str.strip()
    .str.replace(r"\.(SH|SZ|BJ)$", "", regex=True)
    .str.replace(r"\.0$", "", regex=True).str.zfill(6))
end = holdings["EndDate"].astype("string").str.replace(r"\.0$", "", regex=True)
holdings["date"] = pd.to_datetime(end, format="mixed", errors="raise").dt.strftime("%Y%m%d").astype(int)
holdings = holdings.merge(bridge, on="holding_code", how="left", validate="m:1")
matched = holdings.merge(stock, on=["stock_code", "date"], how="left",
                         validate="m:1", indicator=True)
unmatched = matched.loc[matched["_merge"] != "both"].copy()
# 先检查 unmatched；不能把匹配不到的股票和控制变量缺失混为同一类问题。
```

若原始证券代码包含港股，不能用本 A 股面板强行匹配。未匹配的旧码、代码变更期以及半年末不存在行情的情况应单独检查。研究交易行为可使用当时实际持仓；如做投资者可执行策略，还要按基金持仓报告实际公告日推迟信号形成，不能拿报告期末当持仓公开日。

## 辅助字段与核验标记的完整说明

主表除 16 个指标外还保留分子、分母、时点和事件字段。这些列有的是计算输入，有的是审计提示，不能全部不加区别地投入回归。金额分子及平均分母已在前述指标说明中定义；下表补齐其他输出字段。

### 行情与记录身份

| 字段 | 生成方式与缺失含义 |
|---|---|
| `stock_code` | 源证券代码去首尾空格、去末尾 `.0`，补足六位字符串；它是证券代码，不保证等同于跨全部改码历史的统一公司 ID |
| `asof`、`date` | 半年末日期；后者为前者转成的整数 `YYYYMMDD`，不是报告公告日 |
| `price` | 当期 6 月/12 月月行情 `Mclsprc`，元/股；代码没有将它乘价格复权因子 |
| `price_date` | 半年末年份及月份拼接源字段 `Clsdt`（该月最后成交日的日号）；无效日期置空，不能默认恰好等于 `asof` |
| `market_type` | 同一期末月行情的 `Markettype`，不是用当前公司市场类别回填历史 |
| `end_month_trade_days` | 同一期末月的 `Ndaytrd`；只表示这一个月的交易天数，不是半年累计交易天数 |
| `market_cap`、`float_market_cap` | 同一期末月总/流通市值，原千元字段乘 1000；没有期末月记录则缺失 |
| `observed_months`、`return_months` | 半年原始月行数、有效含息收益月数，区别“有记录但收益缺失”与“根本缺月” |

### 财务分子、可用日期与异常提示

| 字段 | 生成方式与含义 |
|---|---|
| `fin_report_period` | 截至 `asof` 已按原始公告日公开的最新报告期；该期数值仍可能因更正而不可用 |
| `fin_announcement` | 所选报告期的原始公告日，不是最近更正日 |
| `fin_age_days` | `(asof−fin_report_period)` 的日数；不是距公告日的日数。当前程序没有设置最大财报年龄阈值 |
| `book_source_available` | 当前资产负债表的可用日，适用于 `book_equity`、`assets`、BM、PB、负债率 |
| `earnings_ttm_available` | 非年报取当前、上年全年、上年同季利润表可用日的最大值；年报只取当前利润表，适用于新增 TTM 分子及相关指标 |
| `balance_yoy_available` | 当前与上年同季资产负债表可用日的最大值，用于资产增长的日期检查 |
| `revenue_yoy_available` | 当前与上年同季利润表可用日的最大值，用于累计收入同比 |
| `roa_source_available` | TTM 利润所需报表与当前、上年同季资产负债表可用日的最大值；年报不要求历史利润表 |
| `roe_source_available` | `balance_yoy_available` 与 `earnings_ttm_available` 的最大值，并同时要求两边必需报表完整 |
| `book_equity`、`assets` | 当前所选报告期的归母权益、总资产；资产负债表可用才输出。其本身不因零值或负值自动置空，下游指标再执行各自分母条件 |
| `income_ttm`、`roa_average_assets` | 经 ROA 所需资产和利润日期筛选后的 TTM 合并净利润、同比平均总资产；详见 ROA 说明 |
| `parent_income_ttm`、`revenue_ttm`、`operating_profit_ttm`、`total_profit_ttm` | 分别为通过利润表日期检查的 TTM 归母净利润、营业总收入、营业利润、利润总额；不依赖资产表有效性 |
| `rd_expense_ttm` | 通过利润表日期检查及 2018 年年报起始条件的 TTM 研发费用；源计算值可能为负，强度指标会另外要求其非负 |
| `roe_average_equity` | 同比两端归母权益均为正、利润及资产负债表可用时的平均权益；最终 ROE 还需要非缺失的归母利润数值 |
| `bs_correction_blocked` | 当前资产负债表有更正标记且未通过日期可用性检查时为 True |
| `roa_correction_blocked` | ROA 必需报表组件中任一项有更正标记，且其可用日缺失或晚于 `asof` 时为 True；年度不检查不需要的旧利润组件 |
| `negative_book_equity` | `book_equity<0` 的布尔结果。当前实现对缺失权益也返回 False，因此 False 不能单独证明权益非负，须同时检查 `book_equity` 非缺失 |
| `financial_extreme_review` | `abs(roa)>1` 或 `abs(bm)>10` 时为 True；两项都缺失时可能为 False，不能代替有效性判断 |
| `controls_complete` | 仅当 `size, bm, roa, ret6m, rec_change` 五列均非缺失时为 True；不包含新增 11 项，不要求数值非负，也不代表全部审计风险消除 |

可用日期的“最大值”列在组件缺失时仍可能有日期，因为其余组件提供了日期。**日期非空本身不等于指标可用**：生产流程还分别检查每个必需组件的日期与数值。更正阻断行的日期甚至可能晚于 `asof`，仅作缺失原因追溯，不能作为当时已知的解释变量。`bs_correction_blocked` / `roa_correction_blocked` 也不涵盖所有缺失原因。

### 评级辅助列

| 字段 | 生成方式与含义 |
|---|---|
| `rec_consensus` | 180 天窗口内、每券商一次投票后的评级中位数，无有效券商则缺失 |
| `rec_brokers` | 最终参与本期共识的不同券商数，无覆盖则为 0；不是报告总数或分析师人数 |
| `rec_latest_publication` | 最终入选券商评级可用日的最大值；名称虽含 publication，实际存的是 `max(Rptdt, DeclareDate)` 后的日期 |

### 股数事件、价格因子和上市状态

| 字段 | 生成方式与含义 |
|---|---|
| `bonus_share_factor_6m` | 对当期除权的有效 SD 事件逐个乘 `1+Amount`；必须 Amount 非负且除权日有效。无有效 SD 倍率时为 1，但有异常 SD 时仍会要求核验，不能把 1 解释为已证明无股份变化 |
| `bonus_event_count` | 按除权日归入当半年的 SD 记录数，包括已落期但 Amount 无效的 SD；不是严格等于有效乘数数量 |
| `special_share_event_count` | 当期 DS/GQ/RO/SN 事件数，加上不满足有效倍率条件的 SD 记录数；不是所有分红事件总数 |
| `event_publication_issue` | 当期任一非现金分红事件公告日缺失或晚于除权日则为 True；现金 CA 不触发此检查 |
| `bonus_listing_cross_half` | SD 新增股份上市日缺失或晚于除权所在半年末时为 True；上市日已知且跨半年时，也标记其上市所在半年 |
| `share_adjustment_review` | `special_share_event_count>0`、`event_publication_issue`、`bonus_listing_cross_half` 三者任一成立则为 True |
| `price_factor_bwd`、`factor_date` | 来自日价格因子表 `114928367` 的 `CumulateBwardFactor` 及 `TradingDate`；向后匹配 `TradingDate≤asof` 的最近记录，不对价格因子再累乘，也不用于调整股数。没有历史因子则为空 |
| `total_shares`、`float_a_shares` | 来自股本变动表 `114008558` 的 `Nshrttl`、`Nshra` 原值；不在本流程重算，不与月行情估值分母互相替换 |
| `capital_date`、`capital_change_type` | 同一股本记录的 `Shrchgdt`、`Shrtyp`；取 `Shrchgdt≤asof` 的最近记录。无公告日约束，所以仅作历史股本核对 |
| `status_date`、`status_announcement` | 上市状态变更表 `091453528` 中 `ChangeDate`、`DeclareDate`；仅取 `ChangedItem=上市状态` 且两日均有效的记录 |
| `status_available` | `max(status_date, status_announcement)`，须不晚于 `asof`；避免提前使用尚未生效或尚未公告的状态 |
| `last_status_event` | 符合时点条件的最新状态记录的 `ValueAfter`。迟到的旧事件不覆盖更新的实施状态，同一可用日有无法消解的冲突则排除该组；没有记录则缺失 |
| `code_change_review` | 代码出现在公司快照的非空 `FormerCode` 对应新码/旧码集合中则为 True；不表示本半年发生过改码 |
| `cross_listed_snapshot` | 当前公司文件 `Crcd` 或 `Commnt` 非空时为 True；仅为跨股类线索，不能当作历史跨境上市状态 |

**股数算例**：半年内两次有效 SD 的 `Amount` 分别为 0.2、0.1，倍率=`1.2×1.1=1.32`。若期初持有 100 股，完全不交易时机械对应 132 股；期末持有 150 股，则送股调整后相对变化=`150/(100×1.32)−1≈13.64%`。这不是从持股比例或价格涨幅推出来的交易量，也没有自动处理配股、拆并股、跨期股份上市等复杂事项。除权日缺失的事件无法归半年，另存核验文件，不应认为它已被半年事件计数覆盖。

匹配表还包括 `info_date`，含义见前面的半年滞后说明。其余 `_lag` 列逐一继承对应主表字段的定义、单位和缺失规则；只有精确上期记录不存在时，原本布尔或计数类字段也会因连接而为空。
